# Login-Signup-Form

Sliding Login & Signup Form : This project is a modern, responsive Login and Signup form with a smooth sliding transition effect between the two forms. It's built using HTML, CSS, and JavaScript. The interface is clean, user-friendly, and fully responsive for different screen sizes.

# Features
Toggle between Login and Signup forms using a sliding UI.

Smooth animation and transition effects.

Responsive design for mobile, tablet, and desktop.

Clean and minimal UI using the Poppins font.
